# Logistics TMS by TAZ · An HTL Inspired Product (beta)

One portal for every node of a supply chain: parcel, LTL, FTL, drayage, final mile, warehousing and international.

- **TMS:** load board, inbound plan, dock schedule, exceptions and documents
- **WMS:** order flow, inventory by SKU with each and case dims, receiving
- **Shipments & PLD:** every tracking number with its contents and package dims; PLD download in Excel or CSV
- **Parcel portal:** rate shop, parcel spend and HTL rate cards
- **HTL services:** custom builds, management services and a vetted carrier network

Everything runs on made-up sample data. Single self-contained `index.html`, no build step.
